새 투자 시작

기존 투자와 별개의 진행 시간과 예상 수익률 조건으로 투자를 생성합니다.

기간형은 3분 간격 · 수익 약 85% / 손실 약 15% · 회원별 종료 목표 ±2%로 진행됩니다. 기간 미정은 자동 지급 페이지 설정을 사용합니다.

추가 투자
